日々の記録帳

個人用・広告なしの日記アプリ(Android)

テキストと写真で日記を記録し、#タグで整理。保存するたびに自分の Google ドライブへ自動バックアップし、別の端末でも復元できます。

プライバシーポリシー

最終更新日: 2026年11月6日

本アプリ「日々の記録帳」(以下「本アプリ」)は、個人が自身の日記を記録するためのアプリです。

1. 収集する情報

本アプリは、ユーザーが入力した日記のテキストおよび添付した写真を端末内に保存します。開発者がこれらの情報を取得・閲覧することはありません。

2. Google アカウントおよび Google ドライブの利用

本アプリは、ユーザーの任意で Google アカウントにログインし、Google ドライブへ日記データをバックアップ・復元する機能を提供します。本アプリが利用する権限は「本アプリが作成したファイルへのアクセス」(drive.file)のみで、ドライブ内のその他のファイルにはアクセスしません。バックアップデータはユーザー自身の Google ドライブにのみ保存され、開発者を含む第三者のサーバーには送信されません。

3. Google API サービスのユーザーデータに関するポリシーへの準拠

本アプリによる Google API から取得した情報の使用は、Google API サービスのユーザーデータに関するポリシー(限定的使用の要件を含む)に準拠します。

4. 広告・解析

本アプリは広告を表示せず、アクセス解析や第三者へのデータ提供も行いません。

5. データの削除

アプリをアンインストールすると端末内のデータは削除されます。Google ドライブ上のバックアップは、ドライブ内の「日々の記録帳」フォルダを削除することでいつでも削除できます。
